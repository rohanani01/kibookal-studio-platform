## How to run v3.0

1. **Studio** — `start.bat` (backend :3001 + frontend :8770) or `OPEN-STUDIO.bat` (opens the HTML directly).
2. **Gallery website** — `cd kibookal-gallery && start.bat` (or `npm start`), serves on **:4000**. The in-Studio Gallery tab connects to it automatically.
3. **Workflow launcher + sync** — `START-WORKFLOW.bat` (in this folder). It:
   - starts the launcher backend (:8899) with `AUTH_DISABLED=true` so it is **always logged in** (no manual sign-in),
   - starts the launcher frontend (:5174) — this is what embeds under the Studio **Workflow** tab,
   - starts `kibookal-gallery/scripts/workflow-to-gallery.js`, which forwards each new launcher output into the **same** Gallery as a Workflow-tagged card (no duplicate gallery system).

Every render from every Studio section (Studio, Comic, Magazine, Characters, Style Lock, Batch, Compose, Upscale, Animate, Look Dev, Layouts) flows to the Gallery automatically via the existing gallery bridge. Workflow outputs flow via the forwarder above.
