## How these were kept consistent (the reusable method)
1. Build a **master book in one style** with characters locked via a **clean figure-crop reference**.
2. **Style-transfer** the master pages into the other styles (keeps layout + characters + captions; changes only the medium).
3. **QC each style** as a contact sheet; re-render any page that drifts or breaks the style.
4. Add final text in **🔤 Typeset** (editable), not baked by AI.

Use these as templates: copy the approach, swap the story/characters.
