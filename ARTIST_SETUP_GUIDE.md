# Kibookal Studio — Artist Setup Guide (1 page)

Welcome! Here's how to start making pages.

## 1. Start the studio
- Double-click **`START-EVERYTHING.bat`**. It opens the gallery, the backend, and the Studio in your browser.
- Leave that black window open while you work (it's the engine). Closing it stops the studio.

## 2. One-time: add your keys
- Click the **⚙ Settings** (top right).
- Paste your **fal.ai key** (for images) and **Anthropic key** (for smart prompts).
- Keys are saved on your machine only. (Each artist uses their own key.)

## 3. Make a page — pick a tool from the top tabs
- **🎨 Style Lock** — pick 1 of 41 locked art styles → type a subject → generate.
- **📐 PageForge** — pick a comic/magazine **layout** (its own typography is preselected; swap if you like) + a style → generate art with blank text zones.
- **🧩 Trigun Kit** — the full mystery-kit pages.
- **🎨 Style Convert** (in **Batch**) — drop in images → convert them all into any style.
- **📖 Magazine / Comic / Diary** — themed page builders.

## 4. Add the final text — **🔤 Typeset** (important!)
- The golden rule: **AI makes the art; you add the words.**
- Open **🔤 Typeset** → load your generated page → pick its layout → type into the reserved zones (the layout's own typography is applied) → **Export flattened PNG**.
- This keeps text crisp, correct, and readable — never trust AI to spell the final text.

## 5. Where your work goes
- Every render auto-saves to the **Gallery**, sorted by section / style / version.
- Use **Download / ZIP** buttons in each tool to grab files. Print files are A5 300-DPI.

## Tips
- Keep characters consistent: reuse the **same reference image** of a character across pages (see the sample books).
- If a page looks off, just regenerate — it's cheap (~₹13 / $0.15 per image).
- Stuck? The **console** (F12) shows a green "integrity OK" line at start; if it's red, tell the team.
